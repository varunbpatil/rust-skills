# Source Coverage

This file records how the two supplemental sources map into the rule set. It is
the audit trail for source ingestion; a source appearing in `README.md` alone
does not count as coverage.

## Inclusion Policy

The repository distills actionable, generally applicable guidance for current
stable Rust. It does not reproduce article narratives, application-specific
walkthroughs, incidental product endorsements, benchmark numbers, or advice
that is only appropriate to a throwaway prototype. Established crates and
tools that directly implement a rule's pattern are included with selection
criteria and dependency trade-offs. When source advice needs qualification,
the linked rule contains the qualified version.

## Maintaining Coverage

When adding another source-derived rule, update this map in the same change. If
guidance is intentionally excluded, record the reason instead of silently
dropping it. Source coverage is conceptual: examples should remain original,
minimal, and validated against the stable toolchain pinned by this repository.
